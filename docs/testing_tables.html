1. Integration Testing Table

Module Testing Input Data Error Handling Expected Output
Auth + User Management Valid credentials (email, password) via POST /login Returns error if credentials do not match any user record User is authenticated, session created, and redirected to the Dashboard.
Auth + User Management New user details (name, email, phone_number, password) via POST /register Checks for unique email and phone number; returns validation errors if password mismatch User account is created with 100 starting points, user is logged in and redirected to Dashboard.
Auth + Middleware Logged-in user with is_suspended = 1 attempts to access system Middleware detects suspended status Access is denied; user cannot reach the Dashboard.
Auth + Admin Module Logged-in user with is_admin = 0 attempts to access /admin AdminMiddleware blocks the request User is redirected away with an Access Denied error.
Item Mgmt + Storage Item creation form (title, category, points, photos[]) via POST /items Rejects empty titles, non-image file uploads, and negative points Item saved to items table; uploaded photos saved to item_photos table with first as primary.
Item Mgmt + Photo System Deleting primary photo via DELETE /items/{id}/photos/{photoId} Rejects if photo does not belong to the item Photo deleted from storage; next available photo automatically promoted as primary.
Borrow Request + Points Borrow request form (item_id, start_date, end_date) via POST /borrow-requests Returns error "Item is not available" if dates overlap an existing active request New borrow_requests record created with status = pending; no points deducted yet.
Borrow Request + Points Approving a pending request via PATCH /borrow-requests/{id}/approve Returns error if request not pending; throws error if borrower has insufficient points Points deducted from borrower and credited to lender; status updated to approved.
Borrow Request + Points Cancelling an approved request via PATCH /borrow-requests/{id}/cancel Returns error "Only approved requests can be cancelled" Points refunded safely to borrower and reversed from lender; status updated to cancelled.
Penalty + Borrow System Lender marks item returned late via PATCH /borrow-requests/{id}/returned Returns error if request is not currently borrowed or overdue Status updated to returned; late penalty auto-created (5 pts × overdue days); points deducted from borrower.
Penalty + Admin Module Lender submits missing report (evidence_photo) via POST /borrow-requests/{id}/missing Returns error if user is not item owner; requires evidence photo Borrow request status → missing; penalty record created as pending awaiting admin.
Admin + Points System Admin approves a pending missing penalty via POST /admin/penalties/{id}/approve Returns error if penalty is not in pending status Penalty status → active; penalty points deducted from borrower; lender is compensated.
Admin + User Management Admin suspends a user via POST /admin/users/{id}/suspend Error if admin tries to suspend themselves or another admin User is_suspended set to 1; suspended_at updated in users table.
Messaging System Starting new conversation (recipient_id, message) via POST /messages/start Prevents messaging yourself; error if recipient doesn't exist New conversations record created; first messages record stored; user redirected.
Messaging System Recipient opens conversation via GET /messages/{conversation_id} Returns 403 if user is not a participant All unread messages from the sender have their read_at timestamp updated.
Rating + User Reputation Borrower rates lender (1-5) via POST /ratings Rejects duplicate rating for the same borrow request Rating stored; rated user's average reputation score is automatically recalculated.

2. System Testing Table

Module Testing Input Data Error Handling Expected Output
New Student Onboarding Full registration form (name, email, phone_number, password) followed by login Rejects duplicate email/phone; validates password confirmation match Account created with 100 starting points; user successfully logged in and lands on Dashboard.
Item Listing Flow Item details form (title, category, description) with 2 uploaded image files Rejects empty title, non-image files, and invalid points values Item saved and listed as Active; primary photo displayed on item card; item becomes publicly visible.
Full Borrow Transaction Borrow request form → lender approves → lender marks borrowed → lender marks returned (on-time) Blocks request if dates overlap; blocks approval if borrower lacks points Points correctly deducted from borrower and credited to lender; status progresses pending → approved → borrowed → returned.
Overdue Return Flow Lender marks item as returned after the scheduled end_date has passed Returns error if item is not in borrowed or overdue status Overdue days calculated correctly; late penalty auto-created (5 pts × overdue days); points deducted from borrower.
Damage Report Flow Lender submits damage report with evidence_photo; Admin reviews and approves it Requires lender ownership & evidence photo; rejects approval if not pending Pending penalty created; upon admin approval, 50 points are deducted from borrower and credited to lender.
Admin Rejects Penalty Admin navigates to Penalties panel and clicks Reject on a pending damage report Returns error if penalty is not currently pending Penalty status updated to rejected; borrower's points remain unchanged; lender receives no compensation.
Messaging Flow User A sends message to User B via item detail page; User B replies from inbox Prevents messaging self; blocks access to conversations the user is not part of Conversation thread created; messages stored sequentially; unread badge shown on navbar; read_at updated when viewed.
Admin Suspends Account Admin enters suspension reason and submits; later clicks Unsuspend on same user Admin cannot suspend another admin or themselves While suspended, student cannot log in; after unsuspending, student can log in and access system normally.
Admin Adjusts Points Admin enters +50 points with reason "Bonus Award"; then -20 points Validates that the input points field is a valid integer User's points_balance correctly increases then decreases; point_transactions logs created for both manual adjustments.
Item Search & Filter Keyword "Camera" entered in search bar; category "Electronics" selected No error thrown if search returns zero results; displays empty state Search results show only matching items; category filter narrows list; clearing filters restores full item listing.
Review & Rating Flow Borrower submits 5-star review with comment and rates lender 4 stars Blocks duplicate review or rating for the exact same borrow request Review appears on item detail page; user-to-user rating stored; lender's average reputation score dynamically updated.
Reports & Analytics Admin navigates to Reports page (no user input required) Prevents crashes if transaction tables are currently empty All report sections load successfully: top lenders, top borrowers, category distribution chart, and monthly transaction trends.
Availability Conflict Second user submits borrow request for same item with exact overlapping dates Returns error "Item is not available for the selected dates" Borrow request is rejected completely; no record is saved to the database; prior existing booking remains wholly unaffected.
Profile & Avatar Update User submits updated name, bio, location, and a new avatar image upload Validates unique email (excluding self); accepts only valid image types Profile updated in users table; new avatar safely stored; updated layout fully displayed correctly on public profile.
